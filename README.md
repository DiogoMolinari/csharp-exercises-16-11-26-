# **Exercícios**

**Exercício 1:** Faça um programa que crie 4 objetos de carro onde tenha marca/fabricante, modelo, ano de fabricação, ano de modelo e valor de venda. Grave esses carros em um vetor e faça a exibição do mesmo.



**Exercício 2:** Faça um programa que crie uma classe "Conta Bancária" e os atributos (Titular-string; Saldo-double). Adicione os seguintes métodos à classe: depositar (recebendo um parâmetro double), sacar (recebendo um parâmetro double), exibir saldo (mostrando o saldo formatado) e ToString com as informações da conta bancária.



**Exercício 3:** Faça um programa que crie uma classe "livro" com os atributos título e autor (string) e número de páginas (inteiro positivo). Crie um construtor que receba esses três valores. Crie a função get para cada uma das propriedades. Reescreva a função ToString para exibir os dados dos livros (vetor).



**Exercício 4:** Faça um programa que crie uma função que calcule o IPVA previsto para o carro, tratando os carros com mais de 20 anos (do exercício 1). Criar uma classe motor com 3 atributos: combustível (tipo), cilindrada e potência. Essa classe motor precisa ser inserida na classe carro (atributo).



**Exercício 5:** Faça um programa que crie uma classe de conta bancária abstrata com as seguintes propriedades: numero, saldo. Os métodos da conta bancária são: depositar, sacar, transferir e pagar. Existem 3 tipos de conta: corrente, poupança e salário. A conta corrente possui a propriedade limite, que é sempre definida automaticamente pelo triplo do saldo. Caso o saldo esteja negativo, o limite é zerado. Na conta poupança todo saque desconta 5% de taxa. Na conta salário, não tem limite nenhum. Faça um programa que gerencie 3 contas em que o usuário escolhe as 3 contas que quer criar.
